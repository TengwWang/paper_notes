# Paper Notes

Figure-first scientific paper notes hosted with GitHub Pages.

## Site

- Homepage: https://TengwWang.github.io/paper_notes/
- Stack: https://TengwWang.github.io/paper_notes/papers/stack/

## Structure

- `index.html`: searchable paper-library homepage
- `papers.json`: paper registry / lightweight database
- `papers/stack/index.html`: Stack paper note
- `papers/stack/metadata.json`: Stack metadata
- `skills/figure-first-paper-html/SKILL.md`: reusable Figure-first paper skill
